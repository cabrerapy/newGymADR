# NP-001.2 — Consolidación de arquitectura

## Alcance

ADR Cross es una aplicación serverless para gestionar alumnos, reservas, pagos, membresías y WOD de un gimnasio de CrossFit. Esta consolidación mantiene las decisiones de NP-000, NP-001 y NP-001.1 e incorpora ADR-ARCH-001, ADR-DB-001 y ADR-COST-001.

## Componentes

1. **Frontend:** Angular y TypeScript, alojado como aplicación estática en S3 y distribuido por CloudFront.
2. **Autenticación:** Amazon Cognito User Pool; los JWT se validan en API Gateway.
3. **API:** API Gateway HTTP API integrada con Lambda Node.js 24/TypeScript.
4. **Backend:** funciones Lambda modulares, bajo demanda, sin VPC ni provisioned concurrency en el baseline.
5. **Datos:** DynamoDB Standard on-demand, diseño single-table, claves compuestas y GSIs sparse.
6. **WOD:** EventBridge Scheduler ejecuta una tarea diaria que publica el WOD visible desde la fecha correspondiente.
7. **Notificaciones:** SES para correos transaccionales con IP compartida.
8. **Infraestructura:** AWS CDK en TypeScript.
9. **Observabilidad:** CloudWatch Logs con retención corta, métricas estándar y alarmas limitadas.

## Reglas de dominio iniciales

- Máximo una reserva por alumno y día.
- Cancelación hasta una hora antes de la clase.
- Pagos para mensualidades, clases individuales y paquetes.
- Inicio de vigencia de membresías definido por administración.
- WOD diario con variantes por nivel u horario.

## Seguridad

- Bucket S3 privado con CloudFront OAC.
- TLS mediante ACM.
- IAM con mínimo privilegio.
- Validación de JWT en API Gateway.
- Conditional writes para restricciones de concurrencia.
- Secretos fuera del repositorio.

## Economía

- Región recomendada: `us-east-1`.
- Presupuesto máximo objetivo: US$ 20/mes.
- Consumo operativo objetivo: inferior a US$ 15/mes.
- No se incluyen soporte AWS de pago, multimedia, SMS, IP dedicada ni servicios premium.
